# ABB ETL Hackathon

This project contains ETL (Extract, Transform, Load) solutions developed during the ABB Hackathon.

## Overview

This repository contains code and resources for ETL processes to handle data transformation and loading tasks.

## Project Structure

```
├── demo/          # Demo files and examples
├── docs/          # Documentation files
├── metadata/      # Metadata configuration files
├── model/         # Data models and schemas
├── quality/       # Data quality checks
├── src/           # Source code
└── tests/         # Test files
```

## Getting Started

### Prerequisites

- Python 3.x
- Virtual environment (recommended)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/rpkay/abb_etl_hackathon.git
cd abb_etl_hackathon
```

2. Create and activate virtual environment:

Windows:
```bash
python -m venv venv
.\venv\Scripts\activate
```

Unix/MacOS:
```bash
python -m venv venv
source venv/bin/activate
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```
